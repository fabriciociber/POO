# Quadro Kanban e participação

## Quadro Kanban

O quadro GitHub Projects deve conter exatamente estas colunas: **A Fazer**, **Em Andamento**, **Em Teste** e **Concluído**. Cada card deve conter ID da tarefa, sprint, responsável e link para evidência.

### A Fazer

- Preparar publicação permanente e registrar URL de produção (US-09).
- Adicionar URL do repositório e do projeto ao README.
- Preencher evidências reais do grupo e revisar apresentação.

### Em Andamento

- Consolidar README, limitações e material da apresentação (US-10).

### Em Teste

- Validar Gunicorn e configuração de ambiente em serviço de nuvem (US-09).

### Concluído

- Calendário público, modelos relacionais, cadastro, login, logout, hash de senha, autorização, CRUD, validações e testes automatizados.

> O quadro acima é uma estrutura inicial versionada. Para avaliação, o grupo deve criar o quadro no GitHub Projects, manter exatamente as quatro colunas e registrar o histórico real de movimentação.
